# 学习资料索引

这里集中放置 Jarvis 的源码阅读、架构理解和面试准备资料。

## 推荐阅读顺序

1. `CODE_READING_INTERVIEW_GUIDE.md`
   - 先看七天总计划和 20 个必读步骤。
   - 按请求链路阅读代码，不建议从 TUI 大文件逐行开始。
2. `PROJECT_LEARNING_NOTES.md`
   - 补充项目整体结构、关键概念和阅读过程中的理解记录。
3. `S3-Agent的自主规划.md`
   - 理解 Agent 如何进行任务拆解、自主规划和多步执行。
4. `S4-Agent的会话伙伴.md`
   - 理解会话状态、上下文和 Agent 与用户之间的持续交互。

## 使用方式

- 第一次通读：只按 `CODE_READING_INTERVIEW_GUIDE.md` 的主顺序走一遍。
- 第二次复习：结合 `PROJECT_LEARNING_NOTES.md` 和 S3/S4 文档补齐设计动机。
- 面试前：回到阅读计划中的 BFCL、权限、事件流和简历证据部分，确认每个表述都能对应到代码。
