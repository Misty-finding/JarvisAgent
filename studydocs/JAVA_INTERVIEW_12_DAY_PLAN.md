## 每天怎么学

每天建议投入 4～5 小时，固定分成四步：

1. **闭卷回答**：先看题目，不看答案，用 1～2 分钟口述。
2. **核对补漏**：只精读答错、答不全和不会举例的题。
3. **二次口述**：用“结论、原理、使用场景、风险”重新回答。
4. **滚动复习**：抽查前一天和三天前的错题。

题目只标三种状态：

- `A`：能独立、完整地说清楚。
- `B`：知道结论，但原理或场景说不完整。
- `C`：不会，或者答案存在明显错误。

复习时间优先给 `C`，其次是 `B`，不要在 `A` 类题目上反复逐字阅读。

## 回答标准

每道题尽量控制在 1～3 分钟，按以下顺序回答：

```text
先给结论
  -> 解释核心原理
  -> 对比容易混淆的概念
  -> 给出实际使用场景
  -> 补充边界、风险或排查方式
```

一道题只有满足下面三点，才能从 `B/C` 升为 `A`：

1. 不看答案可以连续说完；
2. 能承受至少一次“为什么”的追问；
3. 能结合代码、故障或项目场景举例。
