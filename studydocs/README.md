# 学习资料索引

这里集中放置 Jarvis 的源码阅读、架构理解和面试准备资料。

## 推荐阅读顺序

1. `CODE_READING_INTERVIEW_GUIDE.md`
   - 这是 Jarvis 源码学习的唯一主阅读路线。
   - 从 Day 1 到 Day 7 顺序执行，每个主题只讲一次；大文件按指定函数分段阅读。
   - 同时覆盖调用链、七天计划和简历八个方向。
2. `JAVA_INTERVIEW_12_DAY_PLAN.md`
   - Java、数据库、计算机基础和消息队列八股文的 12 天复习表。
   - 适合已经通读一遍后进行主动回忆、错题复习和模拟面试。
3. `PROJECT_LEARNING_NOTES.md`
   - 只在主指南遇到术语不清时作为补充索引，不要求重新通读。
4. `S3-Agent的自主规划.md`
   - 自主规划专题参考。
5. `S4-Agent的会话伙伴.md`
   - Session 与 Memory 专题参考。
6. `SKILLS_GUIDE.md`
   - 解释 `/` 补全列表的来源、Skill 搜索优先级以及通用/项目 Skill 的添加方式。

## 使用方式

- 只按 `CODE_READING_INTERVIEW_GUIDE.md` 的 Day 1～Day 7 阅读一次。
- 每天完成对应测试、图表和 60 秒回答后再进入下一天。
- S3、S4 和项目学习笔记仅用于查漏，不形成第二套阅读顺序。
- 面试前复习主指南末尾的证据表、设计取舍和面试题。
